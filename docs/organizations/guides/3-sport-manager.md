# Sportron at NUST: sport manager

You run one competition, for example *Badminton Men's Singles*.

## Where to start
**Tournaments** tab → **My sports**. You see your sports, today's matches and the **Next** step for each.

## Before the event
1. **Add players**: sport → **Entries** → **Add entry** (or pair / team).
2. **Make the draw**: settings icon → **Close entries & make the draw** → **Draw & bracket** → **Generate**.
3. **Start**: go back to the settings page and tap **Start**.
4. **Set times and courts**: **Matches** → tap a match → **Schedule**.
5. **Scoring rules** (settings page): the usual rules are set. Change them before matches start; scorers cannot.

## Appoint scorers
Settings page → **Scorers** → **Add scorer** → search their username. They get a notification.
Removing a scorer stops them immediately.

## Match day
- A scorer's finished result counts at once and the bracket moves on.
- A match shows who is scoring it, or who scored it.
- **Walkover** or a typed result: tap the match → **Enter result**.
- Wrong result: **Edit result** or **Reset** (reset the next match first if it was already played).

## If a scorer's phone dies
Another scorer (or you) opens the same match and taps **Take over scoring**. The score continues from the last point that reached the server.
If a removed scorer was in the middle of a match, take it over and finish it.

# Sportron at NUST: organizer

You create tournaments and run the ones you create or are added to.

## Create a tournament (about two minutes)
1. **Tournaments** tab → **Organize · NUST** → **Create tournament**.
2. **Name and dates**: name, start date, location, cover picture (optional).
3. **Pick sports**: tap a sport, then the competitions (for example *Men's singles*, *Women's doubles*). The usual rules are already set.
4. **Review**: **Save as draft** (only you and DD Sports see it) or **Save and publish** (everyone sees it).

The tournament page always shows your **Next step**. Tap it.

## Add players
Open the sport → **Entries** → **Add entry** (or **Add pair** / **Add team**) → fill in the form → **Save & add another**.

## Make the draw and start
1. Open the sport → settings icon → **Close entries & make the draw**.
2. **Draw & bracket** (or **Draw & fixtures**) → arrange the order if you want → **Generate**.
3. Go back and tap **Start**.

## Appoint helpers (settings icon on a sport)
- **Sport managers** run one competition: players, draw, times, results.
- **Scorers** only score matches. Add any Sportron user; you can tick more sports at the same time.

## On the tournament's manage page (settings icon)
- **Co-organizers**: only NUST organizers can be added.
- **Show on screen**: put your tournament on a venue TV.
- **Entry form**: make CMS ID, School, Phone or Email required, optional or off.
- **Preview and publish**, **Cancel tournament**, **Delete draft**.

## Match day
Schedule a match (sport → **Matches** → tap it → **Schedule**) with time and court. Fix a wrong result with **Edit result** or **Reset**; you may need to reset the following match first. A finished sport can be corrected with **Reopen sport**.

## If something looks wrong
No internet: you can still look at saved lists, but creating and publishing need a connection. A message saying the account is paused means NUST's access is on hold; contact DD Sports.
